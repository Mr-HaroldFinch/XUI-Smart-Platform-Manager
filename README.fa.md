# 🚀 Universal X-UI Panel Manager (X-UI Smart Platform Manager)

یک اسکریپت Bash برای مدیریت **NX Panel**، **3x-ui**، **Alireza x-ui** و **x-ui کلاسیک**:

- **پشتیبان هوشمند** - اسنپ‌شات سازگار SQLite، رمزگذاری اختیاری AES-256، تشخیص خودکار نوع پنل.
- **مهاجرت / بازیابی** - ورود دقیق پایگاه داده به 3x-ui / Alireza / x-ui یا مهاجرت راهنما به NX Panel. حالت تست همان بررسی‌های مهاجرت واقعی را همراه با امتیاز سرور نشان می‌دهد. روی همین سرور یا یک سرور ریموت (SSH) اجرا می‌شود.
- **بررسی فایل پشتیبان** - کاربران، دامنه‌ها، اینباندها، گواهی‌ها.
- **نصب / به‌روزرسانی پنل** - با Nginx و HTTPS اختیاری.
- **بهینه‌سازی سیستم** - گواهی‌های منقضی، پشتیبان‌های قدیمی، بررسی و امتیازدهی سرور، بررسی پنهان‌بودن VPN، به‌روزرسانی کامل سیستم.
- **به‌روزرسانی خودکار** از همین مخزن، با تأیید SHA-256.
  ### قابلیت‌ها

**پشتیبان‌گیری**
- پشتیبان هوشمند NX Panel، 3x-ui، Alireza x-ui و x-ui کلاسیک با تشخیص خودکار نوع پنل
- اسنپ‌شات سازگار SQLite (کامل یا فقط پنل) و رمزگذاری اختیاری AES-256
- فهرست پشتیبان فقط فایل‌های سالم و خوانا را نشان می‌دهد؛ فایل‌های رمزگذاری‌شده آیکون قفل دارند

**مهاجرت / بازیابی**
- ورود دقیق پایگاه داده به 3x-ui، Alireza یا x-ui، یا مهاجرت راهنما به NX Panel (فقط پیشنهاد می‌شود، اجباری نیست)
- حالت تست: همان بررسی‌های مهاجرت واقعی (امتیاز سرور، دیسک، منابع دانلود، سازگاری، پورت‌ها، DNS) بدون هیچ تغییری
- بازیابی روی همین سرور یا سرور ریموت از طریق SSH؛ هیچ رمزی ذخیره نمی‌شود
- در هر مرحله بازگشت وجود دارد؛ پنل نصب‌شده فقط با تأیید شما پشتیبان‌گیری و جایگزین می‌شود
- بررسی DNS دامنه‌ها و گزارش نهایی سلامت

**بررسی فایل پشتیبان**
- کاربران، اینباندها، دامنه‌ها، ترافیک، گواهی‌ها و نحوهٔ دسترسی به پنل

**نصب / به‌روزرسانی پنل**
- یک منوی واحد که با پنل نصب‌شده تطبیق پیدا می‌کند؛ Nginx و HTTPS اختیاری

**بررسی و امتیازدهی سرور**
- سخت‌افزار، شبکه، NAT (نمایش هم‌زمان IP عمومی و داخلی)، IPv6، موقعیت، سرویس‌دهنده، سرعت
- دسترسی به GitHub و منابع دانلود، بررسی بلک‌لیست IP، امتیاز ۰ تا ۱۰۰ همراه با توصیه
- روی همین سرور یا هر سروری که به آن وارد می‌شوید؛ فهرست اختیاری سرورها (فایل .dat کدشده، بدون رمز)

**بهینه‌سازی سیستم**
- حذف گواهی‌های منقضی/بی‌استفاده، پشتیبان‌های قدیمی و فایل‌های اضافه (همیشه با تأیید)
- به‌روزرسانی کامل سیستم (apt) با گزارش خوانا
- بررسی پنهان‌بودن VPN: یک سرور ریموت از بیرون سرور شما را بررسی و موارد لو‌دهنده را با راه‌حل ساده گزارش می‌کند

**رابط کاربری**
- فارسی و انگلیسی، منوهای رنگی، هدر متحرک، نوار پیشرفت درصدی، گزارش‌های بلند با امکان اسکرول
- هدر فشرده و ثابت در ترمینال‌های کوتاه؛ نشست ریموت به‌وضوح مشخص است
- به‌روزرسانی از GitHub با تأیید SHA-256

نیازمندی‌ها: لینوکس (Debian/Ubuntu پیشنهاد می‌شود)، Bash 4.4+، `curl`، `python3`، `sqlite3`، `openssl` و دسترسی root.

## نصب (با بررسی هش)

```bash
curl -fsSLO https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/XUI-SPM.sh
curl -fsSLO https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/XUI-SPM.sh.sha256
sha256sum -c XUI-SPM.sh.sha256      # باید چاپ کند: XUI-SPM.sh: OK
sudo bash XUI-SPM.sh
```

هش را با صفحهٔ [Releases](https://github.com/YOUR_USER/YOUR_REPO/releases) هم مقایسه کنید؛ اگر دو منبع با هم نخواندند، فایل را اجرا نکنید.

## حریم خصوصی

- **هیچ رمز عبوری ذخیره نمی‌شود.** فهرست اختیاری سرورها (`/etc/moc-networks/servers.dat`، کدشده، دسترسی ۶۰۰) فقط نام، آدرس، پورت SSH، وضعیت، امتیاز و موقعیت را نگه می‌دارد.
- پشتیبان‌ها را می‌شود رمزگذاری کرد؛ رمز را نگه دارید، بازیابی ندارد.
- پیش از اجرا به‌عنوان root، اسکریپت را بخوانید.
