# XUI-SPM - مدیر هوشمند پنل‌های X-UI

یک اسکریپت Bash برای مدیریت **NX Panel**، **3x-ui**، **Alireza x-ui** و **x-ui کلاسیک**:

- **پشتیبان هوشمند** - اسنپ‌شات سازگار SQLite، رمزگذاری اختیاری AES-256، تشخیص خودکار نوع پنل.
- **مهاجرت / بازیابی** - ورود دقیق پایگاه داده به 3x-ui / Alireza / x-ui یا مهاجرت راهنما به NX Panel. حالت تست همان بررسی‌های مهاجرت واقعی را همراه با امتیاز سرور نشان می‌دهد. روی همین سرور یا یک سرور ریموت (SSH) اجرا می‌شود.
- **بررسی فایل پشتیبان** - کاربران، دامنه‌ها، اینباندها، گواهی‌ها.
- **نصب / به‌روزرسانی پنل** - با Nginx و HTTPS اختیاری.
- **بهینه‌سازی سیستم** - گواهی‌های منقضی، پشتیبان‌های قدیمی، بررسی و امتیازدهی سرور، بررسی پنهان‌بودن VPN، به‌روزرسانی کامل سیستم.
- **به‌روزرسانی خودکار** از همین مخزن، با تأیید SHA-256.

نیازمندی‌ها: لینوکس (Debian/Ubuntu پیشنهاد می‌شود)، Bash 4.4+، `curl`، `python3`، `sqlite3`، `openssl` و دسترسی root.

## نصب (با بررسی هش)

```bash
curl -fsSLO https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/XUI-SPM.sh
curl -fsSLO https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/XUI-SPM.sh.sha256
sha256sum -c XUI-SPM.sh.sha256      # باید چاپ کند: XUI-SPM.sh: OK
sudo bash XUI-SPM.sh
```

هش را با صفحهٔ [Releases](https://github.com/YOUR_USER/YOUR_REPO/releases) هم مقایسه کنید؛ اگر دو منبع با هم نخواندند، فایل را اجرا نکنید.

## حریم خصوصی

- **هیچ رمز عبوری ذخیره نمی‌شود.** فهرست اختیاری سرورها (`/etc/moc-networks/servers.dat`، کدشده، دسترسی ۶۰۰) فقط نام، آدرس، پورت SSH، وضعیت، امتیاز و موقعیت را نگه می‌دارد.
- پشتیبان‌ها را می‌شود رمزگذاری کرد؛ رمز را نگه دارید، بازیابی ندارد.
- پیش از اجرا به‌عنوان root، اسکریپت را بخوانید.
